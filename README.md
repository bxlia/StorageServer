# Инструкция по настройке и защите сервера управления

В данном документе зафиксированы все выполненные настройки сети, пользователей и систем безопасности для обеспечения стабильной работы сервера и самописного приложения.

---

##  1. Сетевые настройки и доступ

Сервер имеет постоянный внутренний IP-адрес **`192.168.0.210`**.

### Проброс портов (Port Forwarding) на роутере
Для безопасного подключения из интернета (через белый IP) на роутере настроены следующие правила:
1. **Управление сервером (SSH):**
   * **Внешний порт:** `2222` (кастомный порт для защиты от ботов)
   * **Внутренний порт:** `22` (стандартный порт SSH)
   * **Внутренний IP-адрес:** `192.168.0.210`
   * **Протокол:** `TCP`
2. **Порт для самописного приложения:**
   * На роутере должно быть создано аналогичное правило (например, для портов `8000` или `5000` в зависимости от конфигурации приложения).

### Команды для подключения из командной строки (cmd)
* **Из домашней сети (локально):**
  ```cmd
  ssh zizik@192.168.0.210
  ```
* **Из интернета (через мобильную сеть или другой ПК):**
  ```cmd
  ssh zizik@********* -p 2222

## 2. Управление пользователями и правами

В системе настроены два уровня доступа:

1. **`zizik`** (или `root`) — Администратор системы. Обладает правами `sudo`. Используется для настройки сервера, обновления пакетов и управления безопасностью.
2. **`bulya`** — Ограниченный пользователь, созданный специально для работы самописного приложения.
   * **Директория приложения:** `/opt/my_program`
   * Права на эту папку полностью переданы пользователю `bulya` командой:
     ```bash
     sudo chown -R bulya:bulya /opt/my_program
     ```
   * **Назначение:** Загрузка файлов приложения по протоколу SFTP через FileZilla/WinSCP на порт `2222` и запуск кода без административных прав.

## 3. Система безопасности (Временно отключена для тестов)

Для защиты сервера были установлены и настроены два рубежа обороны. **Внимание:** на время тестирования приложения они переведены в режим `inactive`.

### Брандмауэр UFW (Сетевой экран)
Конфигурация закрывает все порты, кроме явно разрешенных.
* **Команда для включения:** `sudo ufw enable`
* **Команда для отключения:** `sudo ufw disable`
* **Базовые правила (после включения):**
  ```bash
  sudo ufw default deny incoming
  sudo ufw default allow outgoing
  sudo ufw allow 22/tcp  # Разрешить SSH
  # sudo ufw allow НОМЕР_ПОРТА/tcp
  ```

### Fail2ban (Защита от подбора паролей)
Утилита анализирует логи авторизации и временно блокирует IP-адреса, которые несколько раз подряд ввели неверный пароль.
* **Команда для запуска:** `sudo systemctl start fail2ban`
* **Команда для остановки:** `sudo systemctl stop fail2ban`
* **Команда для удаления из автозагрузки:** `sudo systemctl disable fail2ban`
* **Разблокировка своего IP (если случайно забанило):**
  ```bash
  sudo fail2ban-client set sshd unbanip ВАШ_IP
  ```

## 4. Диагностика и мониторинг

На сервере установлена утилита **`htop`** для мониторинга ресурсов (процессор, оперативная память, запущенные процессы) в реальном времени.

* **Запуск:** Введите в терминале команду `htop`.
* **Выход:** Нажмите клавишу `q` или `F10`.
